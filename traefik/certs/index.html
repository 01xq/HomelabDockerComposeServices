🔒 Homelab CA Certificate

Install this certificate on your device to trust all homelab services and eliminate security warnings.

📥 Download Certificate

Installation Instructions

🪟 Windows

  1. Download and double-click homelab-ca.crt
  2. Click "Install Certificate"
  3. Select "Local Machine" → Next
  4. Choose "Place all certificates in the following store"
  5. Browse → Select "Trusted Root Certification Authorities"
  6. Click Next → Finish

🍎 macOS

  1. Download and double-click homelab-ca.crt
  2. It will open in Keychain Access
  3. Select "System" keychain
  4. Find the certificate "mkcert root@docker"
  5. Double-click it → Trust → "Always Trust"

🐧 Linux

sudo cp homelab-ca.crt /usr/local/share/ca-certificates/
sudo update-ca-certificates

📱 iOS/iPadOS

  1. Download the certificate (Safari will prompt to install)
  2. Go to Settings → General → VPN & Device Management
  3. Tap the certificate profile and install it
  4. Go to Settings → General → About → Certificate Trust Settings
  5. Enable full trust for the certificate

🤖 Android

  1. Download the certificate
  2. Go to Settings → Security → Encryption & credentials
  3. Tap "Install a certificate" → CA certificate
  4. Browse and select the downloaded file

🦊 Firefox (All Platforms)

  1. Open Firefox → Settings → Privacy & Security
  2. Scroll to "Certificates" → Click "View Certificates"
  3. Go to "Authorities" tab → Click "Import"
  4. Select homelab-ca.crt
  5. Check "Trust this CA to identify websites"
📝 Note: After installation, restart your browser to see the changes take effect. All *.local domains will be trusted.
